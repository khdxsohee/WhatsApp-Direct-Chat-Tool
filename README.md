# 📲 WhatsApp Direct Chat Tool


A **modern, lightweight, and privacy‑friendly web tool** that allows users to open a WhatsApp chat with any phone number **without saving the contact**.


Built using **pure HTML, CSS, and JavaScript**, this project focuses on real‑world daily usage, clean UI, and zero backend dependency.


---


## ✨ Why This Project?
Saving phone numbers just to send a single WhatsApp message is inefficient. This tool solves that everyday problem with a fast and simple solution that works on **any device**.


Perfect for:
- Delivery riders 🚴‍♂️
- Small business owners. 🏪
- Freelancers 💼
- Customer support teams 📞
- Personal daily use


---


## 🚀 Features
- 📱 Open WhatsApp chat without saving number
- 🌍 Supports international country codes
- 💬 Pre‑filled custom message support
- 🔗 Generates official WhatsApp `wa.me` link
- 📋 Copy chat link with one click
- 💻 100% client‑side (no backend, no tracking)
- 🔒 Privacy‑focused (no data stored)
- 📱 Fully responsive & mobile‑friendly design


---
## ▶️ How It Works
1. Enter the country code (e.g., `92`)
2. Enter the phone number (without spaces)
3. (Optional) Type a custom message
4. Click **Open WhatsApp**
5. Chat opens instantly in WhatsApp (Web or App)
